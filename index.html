連接 Google 試算表資料庫

⚠️ 偵測到 Google Apps Script 尚未發布為「建立新版本」
請至 Apps Script 編輯器點擊右上角 「部署 → 管理部署作業 → 點筆圖示（編輯）→ 版本選『建立新版本』→ 部署」，否則線上網址仍會執行舊版程式。

將 Google Apps Script 部署為「網頁應用程式」後，把產生的 https://script.google.com/macros/s/.../exec 網址貼在下方，即可讓所有裝置即時同步讀寫您的 Google 試算表！

手動同步工具
💡 讓全體服事者免貼網址、打開網頁自動連線的小技巧：
您也可以將網址直接填入 index.html 程式碼中的 DEFAULT_GOOGLE_SCRIPT_URL 變數，上傳到 GitHub 後所有人打開網址就會自動連上您的試算表！
